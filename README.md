# DeepSeek-Tui Homebrew Tap

Install DeepSeek-Tui via Homebrew:

```bash
brew tap Shyboy0499/deepseek-tui
brew install deepseek-tui
```

## What is DeepSeek-Tui?

An AI-native note-taking and research assistant for the terminal with deep [Obsidian](https://obsidian.md) vault integration. Built with Python + Textual.

## Updating

```bash
brew upgrade deepseek-tui
```

## Uninstall

```bash
brew uninstall deepseek-tui
brew untap Shyboy0499/deepseek-tui
```
